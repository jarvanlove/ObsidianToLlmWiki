## 用户只需要说

```text
把这份资料收进当前项目。
```

或者：

```text
把这份资料收进个人知识库。
```

## Agent 内部执行协议

Agent 应自动完成：

1. 判断资料应进入项目层、个人层、共享层还是输出层。
2. 保存原始资料并创建来源笔记。
3. 对文档类资料生成文档地图和章节笔记。
4. 保留页码、slide 或 heading 级来源定位。
5. 检查章节笔记是否包含主题、概念、事实、流程、受限摘录、待追问问题和沉淀候选。
6. 先阅读文档地图和章节笔记，再提炼核心观点、事实、结论、约束和风险。
7. 更新已有页面，而不是只新建孤立页面。
8. 如果资料属于项目，同步更新真正受影响的项目页面。
9. 如果产生跨项目可复用知识，提升到个人层或共享层。
10. 先生成资料沉淀候选报告，再根据候选报告决定是否写正式知识页。
11. 页面变更后补必要链接、记录日志并重建索引。

## 质量底线

- 不允许把长文档只压缩成一篇空泛摘要。
- PDF 必须保留页码引用。
- PPT 必须保留 slide 引用。
- Markdown / 文本 / docx 必须保留 heading 或 section 引用。
- 章节笔记必须有主题、概念、事实、流程、原文摘录、待追问问题和沉淀候选。
- 原文摘录必须受 `excerpt_limit_chars` 限制，不能复制整章原文。
- 正式知识页必须能回链到来源笔记、文档地图或章节笔记。
- 资料沉淀候选报告只列候选，不自动创建正式知识页。

输出时说明：新建了哪些页面、更新了哪些页面、最重要的 3 到 5 个结论、还有哪些值得继续追问的问题。
