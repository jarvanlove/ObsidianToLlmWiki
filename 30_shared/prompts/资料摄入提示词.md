## 用户只需要说

```text
把这份资料收进当前项目。
```

或者：

```text
把这份资料收进个人知识库。
```

## Agent 内部执行协议

Agent 应自动完成：

1. 判断资料应进入项目层、个人层、共享层还是输出层。
2. 保存原始资料并创建来源笔记。
3. 提炼核心观点、事实、结论、约束和风险。
4. 更新已有页面，而不是只新建孤立页面。
5. 如果资料属于项目，同步更新真正受影响的项目页面。
6. 如果产生跨项目可复用知识，提升到个人层或共享层。
7. 页面变更后补必要链接、记录日志并重建索引。

输出时说明：新建了哪些页面、更新了哪些页面、最重要的 3 到 5 个结论、还有哪些值得继续追问的问题。
