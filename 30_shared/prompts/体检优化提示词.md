# 体检优化提示词

## 关联

- [[30_shared/索引|共享索引]]

## 用户只需要说

```text
做一次知识库体检。
```

或者：

```text
检查一下当前 wiki 有没有结构问题。
```

## Agent 内部执行协议

Agent 应自动完成：

1. 运行知识库体检。
2. 检查孤儿页面、过期页面、缺少回链、重复主题。
3. 对明确可安全修复的问题直接修复。
4. 如果发现项目经验应提升到共享层，创建或更新共享页。
5. 生成体检报告。
6. 页面变更后记录日志并重建索引。
