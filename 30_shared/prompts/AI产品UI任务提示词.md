# AI产品UI任务提示词

## 正常开始

```text
开始工作：<页面或流程>，目标用户是 <谁>，核心任务是 <什么>。
```

Agent 自动判断 U0/U1/U2/U3。U2/U3 先完成方向，不直接写生产 UI。

## 指定工具但限制权限

```text
用 Stitch 探索三个差异明显的视觉方向，不改生产代码。
```

```text
以这个 Figma 节点为已批准参考，实现 <页面>。
```

```text
用 <Skill 名称> 审查当前页面的层级、状态和响应式问题，只输出 Visual QA 报告。
```

## 批准和推进

```text
方向 B 批准，按它进入实现。
```

```text
继续当前 UI 任务。
```

## 收工

```text
收工。
```

用户不需要运行脚本。Agent 负责记录点名 Skill、方向批准、截图、Visual QA、无障碍证据和收工门禁。
