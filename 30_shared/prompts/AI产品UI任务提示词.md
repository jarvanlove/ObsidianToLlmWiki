# AI产品UI任务提示词

## 正常开始：只说要做什么

```text
开始工作：帮我做一个 <页面或流程>，给 <谁> 用，主要解决 <什么>。
```

没有参考图时，Agent 自动沿用项目风格；新项目使用稳定默认方向，不要求你先选颜色。

## 觉得不好看时：只说感觉

```text
这个感觉太冷了，想更温暖、有品质一点。
```

```text
太花了，想更清楚、专业一点。
```

Agent 会先判断问题是排版/层级还是整体气质。需要换风格时，只给出 3 个通俗选项；你只需回复：

```text
第二个。
```

或：

```text
就这个，继续。
```

色号、主题等级、审批记录和验收证据都由 Agent 在后台处理。只有你主动说“再给我更多风格”或点名某种颜色时，才展开更多内置方向。

## 指定工具但限制权限

```text
用 Stitch 探索三个差异明显的视觉方向，不改生产代码。
```

```text
以这个 Figma 节点为已批准参考，实现 <页面>。
```

```text
用 <Skill 名称> 审查当前页面的层级、状态和响应式问题，只输出 Visual QA 报告。
```

## 批准和推进

```text
就用第二个，继续。
```

```text
继续当前 UI 任务。
```

## 收工

```text
收工。
```

用户不需要运行脚本。Agent 负责记录点名 Skill、方向确认、截图、Visual QA、无障碍证据和收工门禁。
