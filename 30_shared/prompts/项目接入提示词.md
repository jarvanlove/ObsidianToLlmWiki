# 项目接入提示词

## 用途

当你在一个项目仓库里，希望这个项目以后能持续使用私有 wiki、项目记忆和 AI 项目控制面时，用这句话。

## 用户只需要说

```text
帮我把当前项目接入 wiki。
```

也可以说：

```text
把这个项目接到我的 wiki 系统里。
```

## Agent 内部执行协议

Agent 应自动完成以下动作，不要求用户记脚本名、参数或入口文件：

1. 识别当前项目仓库根目录和项目名。
2. 调用项目接入流程。
3. 创建或更新项目 wiki 主干页。
4. 在项目仓库建立 AI 工具入口和项目控制面。
5. 保留已有项目规则，不覆盖已有入口文件或控制文件。
6. 重建索引并记录必要日志。
7. 告诉用户后续只需要说 `请按当前项目规则工作` 或 `继续做当前项目`。

## 完成后汇报

汇报只需要面向用户说明：

- 项目是否已接入。
- 私有 wiki 中对应的项目位置。
- 是否保留了已有规则文件。
- 新建或更新了哪些项目控制能力。
- 后续最短怎么说。

不要把内部读取顺序当成用户需要背的操作步骤。
