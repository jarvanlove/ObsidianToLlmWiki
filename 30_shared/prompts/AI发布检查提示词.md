# AI发布检查提示词

## 使用场景

准备上线、部署、发版本之前使用。

## 用户只需要说

```text
发布前帮我检查一遍。
```

## Agent 内部执行协议

Agent 应自动读取必要项目规则和项目控制文件，然后输出：

- 本次发布包含哪些任务。
- 是否有未关闭任务。
- 是否有数据库 migration。
- 是否有环境变量变化。
- 是否有权限、安全、支付、数据删除风险。
- 应运行哪些验证命令。
- 哪些验证已经通过，哪些还没跑。
- 发布步骤。
- 回滚步骤。
- 发布后要观察的指标。
- 是否需要更新用户文档、README、FAQ、营销页面。

要求：

- 如果 verify 没跑，不要建议发布。
- 如果回滚方式不明确，标记为阻塞。
- 如果涉及数据库或权限，标记为高风险。
