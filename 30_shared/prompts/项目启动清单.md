# 项目启动清单

## 目的

这不是给 LLM 看热闹的说明，而是每次新项目开始时的固定动作清单。

## 用户只需要说

```text
请按当前项目规则工作。
```

或者：

```text
继续做当前项目。
```

## Agent 内部启动顺序

1. 自动判断当前项目是否已接入 wiki。
2. 自动恢复项目上下文和项目 wiki 位置。
3. 自动读取必要项目记忆和项目控制面。
4. 开始具体任务。
5. 任务过程中持续把重要结论写回 wiki。
6. 页面变更后追加日志并重建索引。

## 什么时候必须执行

- 新项目第一次启动
- 新窗口接手同一个项目
- 项目上下文断掉后重新恢复
- 项目产出新的正式文档时

## 什么时候可以跳过

- 只是做一次无关紧要的临时试验
- 已经在同一个任务里并且项目上下文没有变化

## 原则

- 不要等文档写完才回写 wiki
- 不要让不同窗口同时自由改同一页
- 不要把项目交付物和项目记忆混在一起
- 不要把共享知识留死在单个项目里
