# AI任务执行提示词

## 使用场景

项目已经接入 wiki，并且需要继续推进某个具体任务时使用。

## 用户只需要说

```text
做 TASKS.md 里的下一个任务。
```

或者：

```text
继续做当前项目。
```

如果你已经知道任务，也可以说：

```text
处理这个任务：<任务描述或任务ID>。
```

## Agent 内部执行协议

Agent 应自动完成以下动作，不要求用户背入口文件或读取顺序：

1. 恢复项目上下文和当前任务状态。
2. 确认任务边界、风险等级和影响范围。
3. 如果需求不清或风险较高，先问用户。
4. 如果可以执行，按最小方案实现。
5. 只修改与任务直接相关的文件。
6. 不做无关重构，不新增无关功能。
7. 运行最小相关验证。
8. 更新任务状态、必要项目控制文件和项目 wiki。

## 完成后汇报

汇报应包含：

- 做了什么。
- 修改了哪些文件。
- 行为变化是什么。
- 运行了哪些验证。
- 剩余风险是什么。
- 是否需要用户决策。
