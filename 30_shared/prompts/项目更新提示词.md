## 用户只需要说

```text
继续。
```

或者：

```text
边开发边沉淀。
```

## Agent 内部执行协议

Agent 应自动完成：

1. 恢复当前项目上下文。
2. 理解当前任务与项目状态。
3. 完成任务本身。
4. 把新增事实、决策、风险和任务状态写回项目 wiki。
5. 新来源登记到来源层，并在需要时创建来源笔记。
6. 如果发现跨项目可复用经验，提升到共享层。
7. 页面变更后补必要链接、记录日志并重建索引。
