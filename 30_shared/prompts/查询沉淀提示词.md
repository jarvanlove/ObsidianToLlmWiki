## 用户只需要说

```text
基于当前项目 wiki 回答这个问题。
```

或者：

```text
把这次结论记下来。
```

## Agent 内部执行协议

Agent 应自动完成：

1. 检索相关页面，只读取回答所需的最小集合。
2. 输出结构化答案，并说明依据来自哪些页面。
3. 判断结论是否有长期价值。
4. 有长期价值时，写回项目页、个人页、共享页或输出页。
5. 如果暴露出系统性缺口、重复问题或新模式候选，记录为学习候选。
6. 页面变更后补必要链接、记录日志并重建索引。
