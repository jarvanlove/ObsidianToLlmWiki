# 自然语言启动指令

这个页面只定义用户应该怎么说。文件读取、脚本调用、页面回写是 agent 的内部责任。

## 最小启动

```text
开始工作。
```

继续当前项目：

```text
继续。
```

结束当前任务：

```text
收工。
```

Agent 应自动完成：识别项目是否已接入 wiki；未接入则接入并严格检查；已接入则恢复上下文。`继续` 用于推进当前任务或下一个可执行任务。`收工` 用于整理 diff、验证结果、控制文件更新和 wiki 回写候选。

## 项目接入

```text
帮我把当前项目接入 wiki。
```

Agent 应自动完成：识别项目根目录、运行接入流程、建立项目控制面、创建或更新项目 wiki，并说明以后如何继续使用。

## 继续项目

```text
继续。
```

```text
做 TASKS.md 里的下一个任务。
```

Agent 应自动完成：恢复项目上下文、识别当前任务、确认边界、实现、验证、更新任务状态和必要的项目 wiki 页面。

## 需求变更

```text
这是一个需求变更：<你的新需求>。
```

Agent 应自动完成：先评估影响范围和风险，再更新范围与任务记录，最后只做受影响范围内的局部修改。

## Bug 修复

```text
修复这个 bug：<现象或报错>。
```

Agent 应自动完成：先复现或定位根因，再做最小修复，验证后把原因和结论写回项目记忆。

## 发布检查

```text
发布前帮我检查一遍。
```

Agent 应自动完成：检查任务闭环、验证结果、安全风险、部署风险、回滚和上线后观察项。

## 资料摄入

```text
把这份资料收进当前项目。
```

```text
把这份资料收进个人知识库。
```

Agent 应自动完成：保存原件、创建来源笔记、提炼关键事实，并更新真正受影响的项目页、个人页或共享页。

## 查询与回写

```text
基于当前项目 wiki 回答这个问题。
```

```text
把这次结论记下来。
```

```text
把这个经验提升成共享知识。
```

Agent 应自动完成：检索必要页面、回答问题、判断结论归属，并在有长期价值时回写。

## 使用原则

- 用户只说目标，不说脚本名。
- 用户不需要背入口文件、控制文件或读取顺序。
- Agent 负责把自然语言映射到接入、开发、变更、修复、发布、摄入、检索或回写。
- Agent 汇报时说明做了什么、改了什么、验证了什么、还有什么风险。
