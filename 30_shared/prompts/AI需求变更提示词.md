# AI需求变更提示词

## 使用场景

当用户反馈、试用结果或你自己的判断导致需求变化时使用。不要直接让 AI 改代码。

## 用户只需要说

```text
这是一个需求变更：<粘贴变更>。
```

## Agent 内部执行协议

Agent 应自动读取必要项目规则和项目控制文件，然后输出：

- 这是新增需求、修改需求、删除需求，还是验收标准变化。
- 影响哪些用户路径。
- 影响哪些页面、API、数据模型、权限、外部服务。
- 哪些旧行为必须保持。
- 需要新增或修改哪些测试。
- 最小修改范围。
- 是否需要更新产品范围、架构、任务或发布记录。
- 是否需要拆成多个任务。

要求：

- 不要扩大需求。
- 不要顺手重构。
- 不要把未来版本功能塞进当前版本。
- 优先保持局部修改。
- 高风险或需求不清时，先问用户再实现。
