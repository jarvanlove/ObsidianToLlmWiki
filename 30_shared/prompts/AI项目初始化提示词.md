# AI项目初始化提示词

## 使用场景

当你准备启动一个新项目，或一个已有项目还没有项目控制面时使用。

## 用户只需要说

```text
帮我初始化当前项目的 AI 项目控制面。
```

如果是空项目，可以补充：

```text
- 项目名称：
- 目标用户：
- 核心痛点：
- 解决方案：
- MVP 必须做：
- 当前版本明确不做：
- 技术栈偏好：
- 部署偏好：
- 数据库偏好：
- 主要风险：
```

## Agent 内部执行协议

Agent 应自动完成：

1. 读取当前项目已有文件，判断是空项目、半成品项目还是已运行项目。
2. 创建或更新 AI 工具入口和项目控制面。
3. 把产品范围、架构边界、任务池、验证方式、部署和运维规则写成可执行约束。
4. 如果当前项目还没有验证命令，标注 TODO，不要编造已存在命令。
5. 内容必须具体到本项目，不写泛泛原则。
6. 信息不足时，最多列出 8 个必须确认的问题。
7. 不新增复杂工具链，优先单体、简单、可部署、可测试。

最后输出：

- 创建或修改了哪些文件。
- 哪些信息仍然缺失。
- 下一步建议做哪 3 个任务。
