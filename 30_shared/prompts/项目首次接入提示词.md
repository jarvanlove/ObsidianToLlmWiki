# 项目首次接入提示词

## 用途

当你在一个**还没有接入 wiki 的新项目仓库**里打开 Codex 或 Claude Code，需要先把项目桥接到你自己的私有 vault 时，用这份提示词。

它只负责**第一次接入**。接入完成后，后续任务改用现有的项目接入模板。

## 用户只需要说

```text
帮我把当前项目接入 wiki。
```

## Agent 内部执行协议

Agent 应自动完成：

1. 识别当前项目仓库根目录和项目名。
2. 调用项目接入流程。
3. 建立 AI 工具入口和项目控制面。
4. 创建或更新私有 wiki 中的项目主干页。
5. 保留已有规则和已有控制文件，不覆盖用户原有内容。
6. 运行严格检查，确认接入产物齐全。
7. 把可复用经验提升到共享层，项目专属内容留在项目页。

首次接入完成后，面向用户说明：

- 项目是否已经接通。
- 严格检查是否通过。
- 后续最短怎么说：`开始工作`、`继续`、`收工`。
- 哪些已有内容被保留。
- 哪些项目控制能力被新建或更新。

## 识别失败时的补充指令

如果 agent 无法自动识别项目仓库根目录，可以补这一句：

```text
请先用当前工作目录作为项目仓库根目录，再继续首次接入。
```
