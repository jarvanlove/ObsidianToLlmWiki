# AI任务开始提示词

## 用户说法

```text
开始工作。
```

```text
继续。
```

```text
请按当前项目规则开始这个任务：
<任务描述>
```

## Agent 内部动作

1. 判断项目驾驶舱状态：未接入、已接入空闲、执行中、需要收工。
2. 未接入时先接入 wiki 并运行严格检查。
3. 已接入时读取 `wiki.context.json`、项目入口文件、项目控制文件和项目 wiki 核心页。
4. 判断任务类型：普通任务、需求变更、bug 修复、发布检查、运维排障。
5. 判断风险等级：P3/P2/P1/P0。
6. 输出最小计划、预计触碰文件、验证方式。
7. 涉及用户页面、交互、布局、Token、组件或响应式时，判定 U0/U1/U2/U3 UI 影响；U1+ 创建项目 UI task，U2/U3 先产出方向候选，不写生产 UI。

## 输出格式

```text
任务类型：
风险等级：
验收标准：
预计触碰文件：
验证方式：
需要先确认的问题：
```

高风险、需求冲突、架构变更、数据删除、认证、支付、迁移相关任务必须先停下来确认。
